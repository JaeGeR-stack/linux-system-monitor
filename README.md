# Linux System Monitor

基于 Linux C 语言开发的轻量级系统资源监控与告警系统，支持系统信息采集、TCP 网络传输、多客户端并发处理、异常告警、日志记录及外部配置管理。

## 1. 项目简介

本项目运行于 Linux 环境，通过读取 `/proc` 文件系统和调用系统接口，获取 CPU、内存、磁盘及进程相关信息。

项目采用客户端—服务端（C/S）架构，客户端通过 TCP Socket 将监控数据发送至服务端，服务端使用 pthread 多线程处理客户端连接，并通过 cJSON 解析数据、执行阈值告警判断和记录日志。

## 2. 技术栈

- 开发语言：C
- 操作系统：Ubuntu 24.04（WSL2）
- 编译工具：GCC、Make
- 网络编程：TCP Socket
- 并发编程：POSIX Threads（pthread）
- 数据格式：JSON
- JSON 解析：cJSON
- 系统接口：`/proc`、`statvfs`
- 日志管理：文件持久化、互斥锁保护

## 3. 主要功能

### 3.1 系统资源监控

采集 CPU 使用率、内存使用率、磁盘使用情况和进程数量。

### 3.2 TCP 网络通信

客户端通过 TCP 连接服务端，并定期发送 JSON 格式的监控数据。

### 3.3 多客户端并发

服务端通过 pthread 创建工作线程处理客户端连接，支持最多 32 个客户端并发连接，并实现已结束线程的回收。

### 3.4 JSON 数据校验

服务端检查 JSON 格式、必要字段、字段类型及数值范围。对无效监控数据记录错误，并继续处理后续合法数据。

### 3.5 阈值告警

支持 CPU、内存、磁盘使用率阈值告警。

当指标达到或超过阈值时触发告警，恢复正常后记录恢复信息，并避免同一持续异常状态下重复告警。

### 3.6 日志管理

服务端使用互斥锁保护日志写入，记录客户端连接、监控数据、异常告警、恢复事件及线程回收等信息。

日志保存至 `logs/server.log`。

### 3.7 配置文件管理

服务端从 `config/monitor.conf` 加载 CPU、内存和磁盘告警阈值。

修改配置文件并重启服务端即可生效，无需重新编译。程序对非法配置值进行校验。

## 5. 编译与运行

安装依赖：

```bash
sudo apt update
sudo apt install build-essential libcjson-dev
```

进入项目目录：

```bash
cd ~/linux-monitor
```

编译：

```bash
make
```

运行本地监控程序：

```bash
./monitor
```

运行服务端：

```bash
./server
```

在另一个终端运行客户端：

```bash
./client
```

服务端默认监听 `127.0.0.1:8888`，适用于本机测试。

## 6. 配置说明

配置文件：`config/monitor.conf`

```ini
CPU_THRESHOLD=80
MEMORY_THRESHOLD=85
DISK_THRESHOLD=90
```

三个阈值均以百分比表示，允许范围为大于 0 且不超过 100。

修改后重启服务端即可生效。
